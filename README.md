# Teste do Servo no Android

Este repositório só compila o navegador [Servo](https://github.com/servo/servo) para Android, usando o GitHub Actions.

- A compilação roda sozinha quando o arquivo `.github/workflows/servo-android.yml` é enviado, ou manualmente em **Actions → Compilar Servo (Android) → Run workflow**.
- Quando termina, o APK aparece em **Releases**.
- É um experimento: o Servo ainda é um projeto em desenvolvimento.
